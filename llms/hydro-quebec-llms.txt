# Hydro-Québec

> Hydro-Québec is the government-owned Crown corporation that generates, transmits and distributes almost all of the electricity consumed in Québec, Canada. Its API posture is a clean split: market and grid data is genuinely open through an Opendatasoft-powered portal at donnees.hydroquebec.com serving 26 public datasets over a documented, anonymously callable REST API with an OpenAPI 3.0.3 description and a DCAT catalog export, licensed CC BY-NC 4.0. Consumer data is closed — there is no customer-facing API, no Green Button service, and no third-party consent flow.

Generated by the API Evangelist enrichment pipeline on 2026-07-27 from the artifacts in this repository. Not published by Hydro-Québec — no /llms.txt was found on donnees.hydroquebec.com (HTTP 404) or www.hydroquebec.com (HTTP 200 soft-404 HTML).

## APIs

- [Explore API v2.1](https://donnees.hydroquebec.com/api/v2/console): current, stable, read-only REST API over the 26 public datasets. Base URL https://donnees.hydroquebec.com/api/explore/v2.1. 16 GET operations across Catalog and Dataset tags.
- [Explore API v2.0](https://donnees.hydroquebec.com/api/v2/console): DEPRECATED. Same 16 operations at https://donnees.hydroquebec.com/api/explore/v2.0. Responses carry `ODS-Explore-API-Deprecation` and a `Link; rel="deprecation"` header. Use v2.1.
- [Search API v1](https://donnees.hydroquebec.com/api/v1/console): legacy Opendatasoft Search API at https://donnees.hydroquebec.com/api/datasets/1.0. Live and anonymous, but no OpenAPI/Swagger description is published (/api/v1/swagger.json returns 404).

## Access

- No API key required. Anonymous calls to https://donnees.hydroquebec.com/api/explore/v2.1/catalog/datasets return HTTP 200 with all 26 datasets.
- An optional API key may be supplied as `Authorization: Apikey <key>` (preferred) or `?apikey=<key>`.
- The Opendatasoft platform also implements an OAuth2 authorization code flow (RFC 6749 / RFC 6750) at /oauth2/authorize/ and /oauth2/token/ on this domain; the only supported scope is `all`.
- Rate limit state is returned on every response as `X-RateLimit-Limit`, `X-RateLimit-Remaining` and `X-RateLimit-Reset`, plus per-dataset `X-RateLimit-dataset-*` variants. On 2026-07-27 the domain limit was observed effectively unbounded.
- Only the HTTP GET method is supported. Every operation is safe and idempotent.
- Errors return `{"error_code": "...", "message": "..."}` — not RFC 9457 problem+json.
- Data is licensed CC BY-NC 4.0: attribution required, non-commercial use only.

## Datasets

26 public datasets across three themes — Electricity consumption, Infrastructure and grid, GHG emissions and the energy transition. Notable ones:

- `historique-demande-electricite-quebec` — History of electricity demand in Québec
- `demande-electricite-quebec` — Electricity demand in Québec
- `historique-production-consommation-ec-horaire` — Hourly generation and consumption history (framework agreement method)
- `historique-production-consommation-proxy-horaire` — Hourly generation and consumption history (proxy)
- `production-electricite-quebec` / `historique-production-electricite-quebec` — Sources of electricity generated in Québec
- `importations-exportations-avec-transits` — Electricity imports and exports per market, including wheel-through energy
- `pannes-interruptions` — Ongoing outages and planned service interruptions
- `evenements-pointe` / `evenements-de-pointe-offres-disponibles` — Winter peak demand events
- `consommation-clients-evenements-pointe` — Consumption of customers in a local demand response program
- `facteurges` / `facteurs-directs-ges` / `estimation-emissions-directes-ges` — Direct GHG emission factors and estimates
- `donnees-hydrometriques` / `donnees-hydrometeorologiques` / `historique-donnees-meteo` — Flows, water levels and weather history
- `historique-consommation-secteur-activite-*` — Consumption by industry sector at AR, MRC and municipal granularity
- `calendrier-travaux-degagement-*` — Vegetation control planning (transmission and distribution), JSON and Shapefile
- `repertoire-arbres` — Tree and shrub directory

## Not available

- No customer/consumer usage API. No Green Button Download My Data or Connect My Data.
- No third-party consent or authorization flow for a customer's own consumption data.
- No webhooks, no streaming, no AsyncAPI — the event-shaped datasets (outages, peak events) are polled.
- No gRPC/Protobuf, no GraphQL.
- No first-party SDK or CLI. The GitHub organization github.com/Hydro-Quebec exists but is empty.
- No public Postman workspace or collection.
